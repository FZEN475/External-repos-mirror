# vendor-repo-sync

Сервисный инструмент для автоматической синхронизации и актуализации внешних (vendor) Git-репозиториев.

## Description

Репозиторий обеспечивает синхронизацию сторонних репозиториев.  
Синхронизация происходит по расписанию из любых внешних источников (`git`,`oci`).

### Ключевые функции

* **Многопоточная синхронизация:** Параллельное зеркалирование репозиториев через конфигурационную матрицу пайплайна.
* **Изоляция зависимостей:** Использование локального контура `${CI_SERVER_URL}` в качестве доверенного источника (Single Source of Truth) для внутренних проектов.
* **Выполнение по расписанию:** Процесс синхронизации выполняется по расписанию через механизм **GitLab CI/CD Schedules**:

#### Актуальное состояние и состав репозиториев

Полный перечень синхронизируемых репозиториев, их актуальные версии, а также адреса источников (SRC) и назначений (DST) формируются динамически.

## Usage

### Добавление нового репозитория
Управление пулом синхронизации осуществляется **исключительно** через файл `.gitlab-ci.yml`. Чтобы добавить новый внешний репозиторий, внесите изменения в секцию `parallel:matrix`:

```yaml
- CONCURRENCY_THREAD: "thread_X"
  SRC_GIT_REPOSITORY: "https://xn----ctbjmbaelubel2bo0fh.com"
  DEST_GIT_REPOSITORY: "\${CI_SERVER_URL}/путь/внутри/вашего/gitlab/repo.git"
```

*После слияния изменений в ветку `master` и создания тега, описание релиза (`RELEASE.md`) обновится автоматически.*
